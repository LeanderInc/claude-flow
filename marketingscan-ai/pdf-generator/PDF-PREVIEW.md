## 🚀 How to Generate

```bash
# 1. Install dependencies
cd marketingscan-ai/pdf-generator
npm install

# 2. Generate from audit data
node generate-pdf.js \
  --input ../outputs/marketing-audit-2025-12-14T00-41-20-675Z/complete-audit.json \
  --output report.pdf

# 3. Open the generated PDF
open report.pdf  # macOS
xdg-open report.pdf  # Linux
start report.pdf  # Windows
```
